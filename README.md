# 落·乾坤

*乾坤易 · 离线多端版*

**v1.0.0**

<br />

</div>

> ### ❤️ 致谢
>
> 本应用灵感来源于 Gitee 开源项目 **「乾坤易」** 六爻排盘工具。
>
> 乾坤易由 **@ihsang** 开发维护，其 Web 版 (hexagram.qiankunyi.com.cn) 提供了出色的排盘体验。
>
> **落·乾坤** 在此基础之上以 Flutter 重构，实现离线多端运行。

---

> ### &lt;/&gt; 技术栈
>
> - **Flutter (Dart)** — 跨平台 UI 框架（Android / iOS / Windows / Linux / macOS）
> - **HarmonyOS Sans** — 鸿蒙字体
> - **Provider** — 状态管理
> - **tyme4dart** — 公历 / 农历 / 干支 / 节气 / 宜忌历法
> - **SharedPreferences** — 卦例与设置持久化
> - **Drift (SQLite)** — 预留数据库层（`app_database.dart`）

---

> ### ✨ 功能一览
>
> **🧮 排盘（三大引擎，纯 Dart 离线计算）**
> - 六爻纳甲：手工 / 机器 / 时间 / 数字四种起卦，纳甲装卦、六亲、六神、旺衰、旬空、刑冲合害、世应、变卦
> - 梅花易数：三数 / 日期 / 物象起卦，本卦 / 变卦 / 互卦，体用生克
> - 八字：四柱、五鼠遁时柱、十神、藏干、旺衰、大运（顺逆/起运年龄）、流年、空亡、纳音
>
> **🗂️ 卦例管理**
> - 增删改查、搜索、标签、统计卡、详情弹窗
> - 导出到文件（.json）/ 剪贴板，从文件 / 剪贴板导入（按 id 去重合并）
> - AI 解卦：OpenAI 兼容接口流式输出、多轮追问、重试回退、推理过程折叠展示
>
> **📅 万年历** — 公历 / 农历 / 干支 / 节气 / 生肖 / 宜忌 / 值神 / 六曜 / 二十八宿
>
> **📖 参考资料** — 六十四卦爻辞、京房八宫、神煞、纳音、二十八宿、象意、禽星、动变等 10 个分类
>
> **🧭 工具** — 二十四山罗盘（实时方位 / 详情交叉引用）、排盘结果保存为图片
>
> **🖥️ 多端适配** — 桌面端（>900px）左侧导航栏 + 内容限宽居中；移动端底部导航栏；兼容触控与鼠标
