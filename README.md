# 落·乾坤

*乾坤易 · 离线多端版*

**v1.0.0**

<br />

</div>

> ### ❤️ 致谢
>
> 本应用灵感来源于 Gitee 开源项目 **「乾坤易」** 六爻排盘工具。
>
> 乾坤易由 **@ihsang** 开发维护，其 Web 版 (hexagram.qiankunyi.com.cn) 提供了出色的排盘体验。
>
> **落·乾坤** 在此基础之上以 Flutter 重构，实现离线多端运行。

---

> ### &lt;/&gt; 技术栈
>
> - **Flutter (Dart)** — 跨平台 UI 框架
> - **HarmonyOS Sans** — 鸿蒙字体
> - **Provider** — 状态管理
> - **Drift (SQLite)** — 本地持久化
> - **SharedPreferences** — 设置存储
