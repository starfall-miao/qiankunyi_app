## 〇、CI 已恢复（commit `fix(build)`）

排查 CI 失败时发现：**main 分支自 Flutter 升级到 3.50 起就无法构建**
（最后一次成功构建 2026-09-06，Flutter 3.47 时代），与本次审查的代码改动无关。

根因：Flutter 3.50 的 `flutter_test` 固定 `test_api 0.7.14`，使 `test >=1.24.3`
要求 `analyzer >=13 <15`；而 `drift_dev <2.32` 只接受 `analyzer <11`，
`drift_dev` 与 `test` 无法共存 → `flutter pub get` 直接解析失败。

处置：

| 项 | 旧 | 新 | 原因 |
|---|---|---|---|
| `drift` | ^2.23.1 | ^2.35.0 | 需 drift_dev ≥2.32 才有 analyzer ≥13 支持 |
| `drift_dev` | ^2.23.1 | ^2.35.0 | 同上（analyzer ≥13 <15，与 flutter_test 一致） |
| `sqlite3` | ^2.7.4 | ^3.9.1 | drift_dev ≥2.32 要求 sqlite3 ^3.0.0 |
| `sqlite3_flutter_libs` | ^0.5.28 | 移除 | 官方标记 EOL；sqlite3 3.x 自带 native assets 构建钩子 |
| `build_runner` | ^2.4.14 | ^2.16.0 | 旧版锁 analyzer <7，与新栈冲突 |
| `file_picker` | ^8.1.6 | ^13.3.3 | 8.x 的 android 模块按 compileSdk 34 编译，与 Flutter 3.50 的 `flutter_plugin_android_lifecycle`（要求 ≥36）冲突；13.x API 改为全静态方法（`FilePicker.saveFile` 返回 `Uri`、`pickFiles` 返回 `List<PlatformFile>`），3 处调用已同步改写 |
| `share_plus` | ^7.2.0 | 移除 | 全工程无引用（死依赖），且是唯一仍应用 KGP 的插件（Flutter 未来版本会因此构建失败） |
| Android 构建 | Gradle 8.14 / AGP 8.11.1 / Kotlin 2.2.20 / Java 1.8 | Gradle 9.5.0 / AGP 9.3.1 / Kotlin 2.4.20 / Java 17 | Flutter 3.50 要求 Gradle ≥9.3.1；Gradle 9 移除 `Project.buildDir` setter（改 `layout.buildDirectory`）；KGP 2.4 移除 `android{}` 内 `kotlinOptions`（改顶层 `kotlin{compilerOptions{}}`）；AGP 9 不再支持 Jetifier |
| CI `flutter analyze` | — | `--no-fatal-infos` | Flutter 3.47+ 默认 `--fatal-infos=on`；material 抽离为 `package:material_ui` 后存量导入整片报 info（详见待办 P0） |

已验证：Flutter **3.50.0 / Dart 3.14** 下 `dart run build_runner build` +
`flutter analyze`（0 error / 0 warning，28 info）+ `flutter test`（69 项）全部通过。

### P1 · 流派正确性（需产品决策，涉及断卦结论）

1. **晚子时（23:00-24:00）日柱归属**（六爻 / 八字 / 大六壬）
   现按"日历日"取日柱，23 点起卦/出生仍算当日；tyme 的 `SixtyCycleDay.getHours()`
   已支持 23 点换日。建议做法：`SettingsProvider` 增加「晚子时换日」开关
   （默认开启=传统），起卦与八字统一读取，并在排盘页显示当前流派。
2. **节气当日交节时刻分界**（八字）
   `SixtyCycleDay` 按"节气日 0 点"换柱；出生在立春当日 0:00–交节时刻之间
   会被提前换年/月柱。需改用 `SolarTime`/节气精确时刻比较。
3. **大六壬三传九宗门起课**：当前为简化取法（已在界面明确标注）。若要正式化，
   需实现贼克/比用/涉害/遥克/昴星等取初传规则 + 传法（进退/间传等）。
4. **六爻伏神爻位**：`hiddenFuShen` 仅存"六亲 干支"，缺所伏爻位与飞神，
   建议升级为结构化字段（伏位 + 飞神），并考虑序列化兼容。

### P2 · 数据与产品能力

6. **`PaipanResult.naYin` / `shenSha` 死字段**：引擎从不赋值，

8. **卦例导出/分享**：PDF 报告、排盘图水印/二维码（原先讨论的候选方向）。
